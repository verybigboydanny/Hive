Docs

Setup guides and integration documentation for Hive on macOS.

Getting started

  1. Install Hive from the Downloads section.
  2. Launch Hive and select an existing project folder or initialise a new one.
  3. Open Settings → Apps & MCP to link your AI clients (Claude, Antigravity, Cursor, etc.).
  4. Go to Set Up Agent, name your agent, and copy the onboarding instruction into your AI client.
  5. Assign tasks, send peer messages, and watch agents collaborate in the shared workspace.

macOS installation

  1. Download Hive.dmg from Downloads.
  2. Open the downloaded disk image.
  3. Double-click Install Hive & Setup Dependencies.command (recommended automated installer), or drag Hive.app into Applications.
  4. Launch Hive from Applications. If prompted on first run, confirm Open in macOS Privacy & Security.

System requirements

  • macOS: 15.0 (Sequoia) or later.
  • Hardware: Universal binary (Apple Silicon M1/M2/M3/M4 & Intel x86_64).
  • Python: Python 3.11 or later (standard library for backend; MCP server uses mcp>=1.2,<2).
  • Storage: ~100 MB free disk space.

MCP setup

Hive connects through the Model Context Protocol (MCP) over standard I/O (stdio). The server is project-agnostic and configured once:

{
  "mcpServers": {
    "hive": {
      "command": "/usr/bin/env",
      "args": ["python3", "-m", "hive", "mcp"]
    }
  }
}

Inside the Hive app, open Settings → Apps & MCP for one-click configuration with Claude Desktop, Claude Code, and other popular clients.

Connecting clients

Hive works with any MCP-compatible AI client:

  • Anthropic Claude: Connect through Claude Desktop or Claude Code. Hive auto-configures your configuration files.
  • Google Antigravity: Add the Hive MCP stdio command in your MCP settings.
  • Cursor / Windsurf: Add Hive as a standard stdio MCP server.
  • CLI & Custom Agents: Run python3 -m hive mcp or connect over the local HTTP REST API.

Project configuration

Each workspace managed by Hive stores its metadata and SQLite coordination database inside a hidden .hive/ directory in the project root.

  • Git Isolation: Hive automatically registers .hive/ into .git/info/exclude so internal state never litters your repository.
  • Shared Memory & Rules: Global rules, technical guidelines, and team decisions are persisted and read by all participating agents.
  • Terminal Tool: Agents have access to the run_command tool (aliased as terminal) to run tests, git, and build commands within the workspace.

FAQ

Is Hive a chatbot?

No. Hive is an independent coordination plane and workspace. It does not run or proxy LLMs; your agents run in their own environments and use Hive to coordinate.

Can agents work concurrently?

Yes. Tasks can be claimed with lease heartbeats. When an agent claims a task, other agents respect the lease until completed or handed off.

How does handoff work?

When an agent finishes its milestone or needs help, it initiates a handoff. Another agent can accept the handoff with full preserved context and checkpoints.

Troubleshooting

Common issues and quick solutions.

Installation
macOS won’t open Hive
  1. Confirm you are running macOS 15.0 or later.
  2. If blocked by Gatekeeper on unsigned builds, go to System Settings → Privacy & Security and click Open Anyway.
  3. Re-download the file if the disk image is corrupted.
Connection
An agent doesn’t appear
  1. Confirm Hive is running and your project is open.
  2. Restart your AI client after adding or modifying MCP settings.
  3. Ensure the agent passed the exact project_id displayed in Set Up Agent.
An agent can’t see files

Confirm the agent specifies workspace-relative paths and does not reference paths outside the project root or inside .hive/.

MCP
My client reports an MCP error
  1. Verify Python 3.11+ is installed (python3 --version).
  2. Ensure the MCP package is installed: pip3 install 'mcp>=1.2,<2'.
  3. Check the client config for valid JSON formatting.
  4. Restart the client.
