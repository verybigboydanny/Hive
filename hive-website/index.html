Troubleshooting

Specific errors and fixes will be added as Hive ships.

Installation
macOS won’t open Hive
  1. Check the requirements.
  2. Re-download the file.
  3. Open it from Applications; review any prompt in Privacy & Security.
Connection
An agent doesn’t appear
  1. Confirm Hive is running.
  2. Restart the client after changing MCP settings.
  3. Check it joined the right project.
An agent can’t see files

Check the project’s file access and that the agent uses the intended project.

MCP
My client reports an MCP error
  1. Check the config for invalid JSON.
  2. Match the command shown in Hive.
  3. Restart the client.
